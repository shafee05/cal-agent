Cal — calendar booking agent

A small TypeScript agent that checks free slots, books meetings, lists bookings and cancels them. Demo data only — nothing here touches a real calendar.

No API key is configured for this demo, so the agent runs on its built-in rule-based planner. With an OPENAI_API_KEY set, the same agent loop uses a real LLM for tool-calling. Bookings reset per deployment instance.
